# Smart Water & Energy App

Aplicativo mobile em React Native para monitoramento da estação de água e energia.

## Integrantes
- Gustavo Nobre Coppola (RM561423)
- Pedro Sinnes martinez (RM566017)

## Como Executar
1. Clone o repositório.
2. Instale as dependências: `npm install`.
3. Rode o app: `npx expo start`.
4. Abra no navegador (w) ou no celular (Expo Go).

## Funcionalidades
- Dashboard com níveis, vazão e consumo.
- Gráfico de evolução do nível da água.
- Tela de histórico de alertas.
- Navegação por abas.
- Tratamento de API Offline (aviso se o backend estiver desligado).
